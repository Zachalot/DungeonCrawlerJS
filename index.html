WASD / Arrows: move · Mouse: aim · Click / Space: attack · 1 / 2 / 3: sword / bow / staff · Hold Q: potion wheel · I: inventory · C: character · F: interact · Esc: menu / close
This game must be served over HTTP. Browsers block ES modules on file://.
Run npm start in the project folder, then open the address it prints (normally http://localhost:8080), or play online at zachalot.github.io/DungeonCrawlerJS.
